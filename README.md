# سبائك الفخامة — لوحة أسعار الذهب

لوحة أسعار ذهب عربية (RTL) تعمل بالكامل على استضافة ثابتة (GitHub Pages) بدون خادم خاص،
وتعرض سعر الأونصة والعيارات بالريال السعودي مع مخطط تفاعلي وحاسبة أسعار.

## مصادر البيانات (مجانية 100%، بلا مفاتيح)

| # | المصدر | الاستخدام | ملاحظات |
|---|--------|-----------|----------|
| 1 | خادم Cloudflare Worker الخاص `sabaaek-gold-api.osa60x.workers.dev` | الأساسي: `/quote` + `/history?range=24h` | يحفظ سجلاً تاريخياً لمدة 24 ساعة |
| 2 | `api.gold-api.com/price/XAU/USD` | احتياط مباشر (CORS) | مجاني وغير محدود، بلا مفتاح |
| 3 | `api.goldprice.dev/v1/prices?symbol=XAU-USD-SPOT` | احتياط ثانٍ | ~100 طلب/ساعة لكل IP بلا مفتاح |
| 4 | `xaus.com/api/v1/spot` | احتياط ثالث (+ فضة ونسبة الذهب/الفضة مجاناً) | بلا مفتاح |

تُرفض القراءات الشاذة (>20% انحراف أو أقدم من القراءة الحالية) تلقائياً،
ويُعرض آخر قراءة سليمة من `localStorage` عند انقطاع كل المصادر.

## الميزات

- سعر الأونصة (XAU/USD) + العيارات 24 / 22 / 21 / 18 / 14 بالريال لكل غرام
- سعر الفضة ونسبة الذهب/الفضة
- مخطط تفاعلي بمديات: منذ الفتح / 24 ساعة / 7 أيام / 30 يوم (تتجمع بيانات 7/30 يوماً محلياً أثناء الاستخدام)
- عدّاد متحرك للأسعار مع توهج اتجاه الحركة (أخضر/أحمر)
- شريط أسعار متحرك (Ticker) مع توقف عند التمرير
- حاسبة سعر فورية (جرام / أونصة / تولة × العيار)
- مؤشر موضع السعر داخل نطاق الفترة (أعلى/أدنى)
- تحديث تلقائي كل 30 ثانية مع حلقة عد تنازلي، وتراجع تدريجي عند فشل المصادر
- مشاركة عبر واتساب / مشاركة النظام / نسخ
- PWA: تثبيت على الجهاز + عمل دون اتصال (Service Worker)
- اختصارات لوحة المفاتيح: `R` تحديث · `S` مشاركة · `1-4` مدى المخطط
- دعم `prefers-reduced-motion` وإمكانية وصول كاملة (ARIA + تخطي الروابط)

## النشر

`push` إلى `main` ينشر تلقائياً عبر `.github/workflows/deploy-pages.yml`.
يعمل الموقع من أي مسار (جذر أو مجلد فرعي) لأن كل الروابط نسبية.

## تخصيص

- استبدال الخادم الوسيط: عرّف المتغير قبل تحميل الصفحة
  `<script>window.SABAAEK_WORKER_URL='https://example.workers.dev'</script>`
- تعديل العيارات: عدّل مصفوفة `KARATS` في `index.html`
- تعديل فترة التحديث: `CFG.REFRESH_MS` في أعلى السكربت

## ترخيص البيانات

المصادر المذكورة مجانية للاستخدام الشخصي واللوحات؛ يُذكر اسمها في واجهة الموقع
(شريط الحالة) وفاقداً للشفافية عند التحويل الاحتياطي بين المصادر.
